# AVIOR KARTING

**АИС «Бронирование карта»**

Учебный проект по дисциплине «Технологии программирования».

## Описание

Прототип веб-интерфейса автоматизированной информационной системы для бронирования заездов на картодроме AVIOR KARTING.

## Основные возможности интерфейса

- Просмотр площадок и доступных услуг.
- Бронирование заездов.
- Выбор типа карта и времени.
- Просмотр и управление бронированиями.
- Личный кабинет клиента.
- Панель администратора.
- Панель руководителя.
- Магазин экипировки.

## Технологии

- HTML5
- CSS3
- JavaScript (демонстрационные сценарии интерфейса)

## Структура проекта

- `UI/index.html` — разметка интерфейса.
- `UI/styles.css` — стили интерфейса.

*Учебный прототип. Не является готовой системой бронирования.*
