# AVIOR KARTING

**АИС «Бронирование карта»**

Учебный проект по дисциплине «Технологии программирования».

## Описание проекта

AVIOR KARTING — учебный проект автоматизированной информационной системы для бронирования заездов на картодроме.

Проект разрабатывается поэтапно в рамках лабораторных работ.

## Основные возможности проекта

- Просмотр площадок и доступных услуг.
- Бронирование заездов.
- Выбор типа карта и времени.
- Личный кабинет клиента.
- Панель администратора.
- Панель руководителя.
- Магазин экипировки.

## Лабораторные работы

### Лабораторная работа №5 — Пользовательский интерфейс и модель данных

Папка `UI/`:
- `index.html` — разметка интерфейса.
- `style.css` — оформление интерфейса.

### Лабораторная работа №6а — Работа с JavaScript

Папка `Lab6a/`:
- `index.html` — HTML-страница проекта.
- `style.css` — стили.
- `js/` — классы предметной области, универсальная коллекция, тестовые данные и методы работы с объектами.

Реализованы конструкторы объектов, добавление, редактирование и удаление данных, фильтрация, сортировка и пагинация.

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
